Token Radar ranks pre-token DeFi protocols by implied value: every protocol in a sealed DefiLlama snapshot that records no token and is not a wrapped, staked or bridged product of one that trades, scored by TVL times a category multiple calibrated on the snapshot's own live-token protocols, times seven-day growth and time run with no token. The dashboard is a static page with a sortable, filterable board, a detail view for every protocol with its model breakdown and an eight-step farm plan, and a live-token view set aside with market caps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
